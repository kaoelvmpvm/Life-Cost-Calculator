# Google 試算表跨裝置投票：啟用步驟

本模組使用你提供的 Google 試算表作為資料庫：

https://docs.google.com/spreadsheets/d/19p_AsOe6_ndC1jEPjnk_hERdGXCE3Ft0g7UePBIZXig/edit

> 此頁面目前是「程式已完成，待授權與部署」狀態。GitHub 原網站仍保留可使用的單機示範投票；完成第 1～6 步後，網站會自動切換為跨裝置投票。

## 1. 在試算表建立 Apps Script 專案

1. 以擁有該試算表編輯權限的 Google 帳號開啟連結。
2. 依序點 **擴充功能 → Apps Script**。
3. 找到預設的 **Code.gs**，用本儲存庫 `apps-script/Code.gs` 的**全部內容取代**。
4. 左側點 **＋ → HTML**，檔名輸入 **VoteApp**（不要再輸入 .html）。
5. 將 `apps-script/VoteApp.html` 的**全部內容貼入**。
6. 儲存專案。Code.gs 內已填入此試算表 ID，不必另改資料庫網址。

重要：若試算表不是你擁有，必須確保 Apps Script 部署者對試算表具有編輯權限。不要把試算表設成「知道連結的任何人可編輯」。

## 2. 設定教師管理密語

在 Apps Script 左下角 **專案設定（齒輪） → 指令碼屬性 → 新增指令碼屬性**：

- 屬性：`TEACHER_KEY`
- 值：自行設計一組**至少 16 字元**的強密語（英文大小寫、數字、符號混合較佳）。
- 儲存。

不要將密語貼進 GitHub、公開試算表或學生教材。學生只需要班級場次代碼，不需要管理密語。

## 3. 部署為網頁應用程式

1. Apps Script 右上角選擇 **部署 → 新增部署作業**。
2. 類型選 **網頁應用程式**。
3. **執行身分：我**（部署該 Script 的 Google 帳號）。
4. **誰可以存取：任何人**（若學校 Google Workspace 政策不允許，請先確認管理員的限制）。
5. 點 **部署**，依 Google 提示完成授權。
6. 複製產生的網頁應用程式網址，格式通常為：
   `https://script.google.com/macros/s/AKfycb.../exec`

此網址屬於投票頁入口，**不是** Google 試算表的分享網址。

## 4. 先直接測試 Apps Script 投票頁

1. 在新瀏覽器分頁開啟第 3 步的 `/exec` 連結。
2. 切換至「教師管理」，輸入 `TEACHER_KEY`。
3. 按「建立新場次」，此操作會自動在試算表建立：
   - `投票場次`：場次代碼、班級標籤、狀態、建立與結束時間。
   - `投票紀錄`：投票時間、場次代碼、題號、選項、匿名裝置雜湊。
4. 複製畫面中的 6 碼班級代碼。
5. 使用另一台裝置（或另一個瀏覽器）開啟相同 Apps Script 網址，選「學生投票」，輸入代碼。
6. 分別投 Q1、Q2。教師頁約每 10 秒更新。
7. 確認試算表出現紀錄、重複按鍵不重複計票、結束場次後學生無法新增票。

**本資料表儲存的是匿名裝置雜湊，而非學生姓名。** 仍建議不要把投票原始資料分享給班級成員。

## 5. 接入既有 GitHub Pages 網站

找到 GitHub 檔案 `js/cloud-config.js`：

```js
window.LIFE_COST_CLOUD_VOTE_URL = "";
```

將空字串 `""` 換成第 3 步的完整 `https://script.google.com/macros/s/.../exec` 網址，儲存提交。

原網站 `index.html` 會偵測合法網址，自動將「單機模擬投票」切換成「跨裝置匿名投票」嵌入版。其他教材、試算邏輯、思辨題目及學習單均維持原樣。

若 Google 對嵌入頁面或瀏覽器第三方 Cookie 有限制，請點網站提供的「獨立投票頁面」連結；後端統計仍相同。

## 6. 後續更新與使用

- 修改 **Apps Script 的 Code.gs / VoteApp.html** 後，需在 **部署 → 管理部署作業 → 編輯** 選擇**新版本**並更新部署；避免網頁仍顯示舊版。
- 修改 GitHub 網站的外觀與教材，不必重新部署 Apps Script。
- 每一個班級建立不同場次代碼，避免票數混雜。
- 教師結束場次後，既有紀錄保留，不自動刪除。
- 學生端只有送出投票才寫入；教師端每 10 秒讀取一次彙總，降低服務配額負擔。

## 使用限制

1. **匿名不等於絕對一人一票**：以瀏覽器匿名裝置識別碼限制每題一次；更換裝置、清除瀏覽器資料仍可能重投。
2. **不是毫秒級資料推播**：教師每 10 秒更新一次結果，課堂使用屬於近即時同步。
3. **多人同時寫入採鎖定**：如遇 Google Apps Script 配額／鎖定等待錯誤，學生可再次送出；程式會防止同一匿名裝置識別碼的重複計票。
4. **正式上線需實機驗證**：請先做跨兩台裝置的試投，再正式在全班使用。
5. **注意敏感議題**：Q1 涉及生理用品使用經驗，避免公布個別作答，建議在班級結束後依校內資料治理規範處理紀錄。

## 驗證狀態

- 已寫入 GitHub：Apps Script 後端、投票 UI、網站嵌入介面及靜態回歸測試。
- 尚未能直接寫入 Google 試算表或代替帳號授權部署。
- 尚未取得正式 Apps Script `/exec` 網址，因此 `js/cloud-config.js` 仍為空字串，網站保留單機模擬模式。
