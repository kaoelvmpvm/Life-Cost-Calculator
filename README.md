# 月經平權：生理期開銷與生命成本試算器

高中月經平權互動教具。以原始 `code_artifact.html` 為基礎，**保留教材中的知識敘述、三項思辨主題、兩道投票題目、數值選項及試算公式**，改善操作與列印體驗。

## 使用

直接開啟 `index.html`，或在 GitHub Pages 上公開。手機、平板與電腦都可使用。

- 調整初潮、停經、經期天數、每日衛生棉數量、用品價格與夜用比例，查看原有生涯成本估算。
- 四項延伸／隱形開銷保留原教材金額與預設勾選。
- 成本圖表新增文字占比與估算公式說明；圖表無法載入時，文字版仍然可用。
- 可儲存情境 A／B，對比不同參數下的估算。
- 三張思辨卡片可展開與收合，原有問題內容完整保留。
- 投票為**單機示範**，從 0 票開始，可在同一裝置重複點按模擬累計，**不是即時跨裝置同步、也不代表每位學生一票**。
- 反思筆記只暫存於目前瀏覽器分頁，可自行清除；不傳送至伺服器。
- 列印時以 A4 學習單樣式整理試算設定、結果與反思筆記。

## 程式結構

| 路徑 | 功能 |
|---|---|
| `index.html` | 原有教材內容與語意化頁面 |
| `css/styles.css` | 響應式、無障礙、列印樣式 |
| `js/cost-model.js` | 原教材數值與計算模型 |
| `js/app.js` | 操作事件、圖表、比較、投票、筆記 |
| `tests/cost-model.test.cjs` | 核心公式回歸測試 |

## 測試

需 Node.js 18 或以上：

```bash
node --test tests/cost-model.test.cjs
```

核對預設值：38 年、456 次、13,680 片衛生棉、單月 NT$686、生涯 NT$312,816。

## 已知限制與下一步

- 本專案目前為靜態網站；多人跨裝置即時投票需要另行設定後端、存取權限與匿名隱私規範，尚未提供。
- Tailwind CSS、Chart.js、FontAwesome 與 Google Fonts 仍透過外部 CDN 載入。**完全離線與生產級 CDN 依賴管理尚未完成**；若 CDN 不可用，純文字試算仍可顯示，但視覺外觀可能不完整。
- 生涯成本模型是教材所設定的情境估算，不納入通膨、價格變動或個人週期差異的預測；與原計算方式相同。
- PDF/列印分頁效果需在實際瀏覽器依裝置與列印設定再做視覺驗證。

## 資料與隱私

無使用者帳號、無伺服器資料蒐集。投票只在本裝置記憶體中累計，重整頁面歸零；反思筆記以 `sessionStorage` 暫存，關閉分頁後由瀏覽器管理其生命週期，共用電腦使用完畢請按「清除本分頁心得」。
